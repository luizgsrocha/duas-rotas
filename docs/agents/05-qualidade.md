# Agente 05 — Qualidade e testes
**Objetivo:** impedir regressões verificáveis.
**Escopo:** testes, scripts e GitHub Actions.
**Critérios:** sintaxe JavaScript, integridade de cities.json, contratos básicos de interface; evoluir para testes de itinerários com mocks e integração.
**Procedimento:** reproduzir bug; criar teste; corrigir; executar CI; reportar cobertura e lacunas.
**Entregáveis:** testes, relatório de falhas e evidências.
**Limites:** checks estáticos não comprovam resultados reais do provedor de caronas.
